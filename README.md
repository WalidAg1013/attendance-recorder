# Student Attendance Management System

A Python command-line project for managing student records and class attendance.

## Features

- Register, search, view, and delete student records
- Mark daily attendance as Present, Late, or Absent
- Filter attendance records by student or date
- Calculate overall and per-student attendance statistics
- Flag students with attendance below 60%
- Export a text summary report
- Save data locally as one JSON record per line in `students.txt` and `attendance.txt`

## Requirements

- Python 3
- No third-party packages required

## Run

```bash
python attendance_system.py
```

The sample data uses fictional names and IDs. The program creates or updates the data files in its working folder.
